# Changelog

## [0.1.0] — 2026-08-29

### Added
- Ядро спайковой симуляции: `DiomaBrain` — LIF-alpha динамика (Shiu et al.
  2024), mean-field дофаминовая STDP за тик, мягкий гомеостаз, отложенные
  награды; бит-в-бит паритет с Rust-движком dioma-engine на золотом следе
  (240/240 тиков, моторные суммы точные).
- `GoldenRunner` — реплей сценария золотого следа (упрощённый контракт
  существа без крови/гиппокампа).
- `Json` — минимальный JSON-парсер (без внешних зависимостей).
- `SmokeRunner` — headless-смоук для `-executeMethod`.
- Тесты EditMode: LIF (спайк/тишина фона), паритет золотого следа,
  обучение меняет веса.
