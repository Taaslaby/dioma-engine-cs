# Dioma Engine

## О проекте

Dioma Engine — детерминированное headless-ядро для выращиваемых спайковых организмов в Unity. Организм состоит из нейронного мозга, биохимического тела, клеточного слоя и интерфейса с миром.

Проект ценит три свойства:

- **поведение**: организм должен не просто считать спайки, а воспринимать, учиться, уставать и действовать;
- **воспроизводимость**: одинаковые входы и seed дают одинаковую траекторию;
- **расширяемость**: новые виды, модели нейронов и физиология добавляются без разрушения старого контракта.

## Быстрый старт

1. Откройте корень Unity-пакета.
2. Запустите `scripts/verify.sh`.
3. Изучите `architecture.ru.md` перед изменением порядка фаз.
4. Добавляйте новое состояние только вместе с тестом детерминизма и границ.

```bash
scripts/verify.sh
```

## Границы проекта

```text
Dioma.Data   → сохранения и форматы
Dioma.Spikes → мозг и обучение
Dioma.Bio    → кровь, клетки и ткань
Dioma.Body   → интеграция мозга и тела
Dioma.World  → тестовый мир
```

`Spikes` и `Bio` намеренно независимы. Их связывает только `Body`. Это не стилистическое соглашение, а защита от скрытых обратных зависимостей и нарушения численного паритета.

## Что считать готовым изменением

Изменение считается завершённым, когда:

- публичный контракт и единицы измерения описаны;
- сохранён порядок вычислительных фаз;
- добавлены тесты для нормального, граничного и повторного прогона;
- `scripts/verify.sh` проходит без изменений золотых следов;
- документация на русском и английском остаётся синхронной.
