# Клеточная биология

## Зачем нужен этот слой

`Blood` описывает системную химию организма. Но в живой ткани гормон не возникает мгновенно во всей крови: клетка получает сигнал, открывает кальциевый ответ, выпускает содержимое везикул, после чего вещество проходит через тканевой отсек в кровоток.

```text
нейронный или физиологический сигнал
                ↓
        BioCellRuntime
 signal → calcium → vesicles → secretion event
                                  ↓
                         TissueChemistry
                    local storage / decay / transport
                                  ↓
                              Blood.Update()
```

Это разделение даёт локальность, задержку, насыщение и физически понятную точку для будущих клеточных типов.

## Ответственность компонентов

| Компонент | Отвечает | Не должен знать |
|---|---|---|
| `BioCellRuntime` | кальций, везикулы, выброс | индексы `Chem`, `Blood`, Unity, мир |
| `BioEvent` | перенос результата шага | как событие будет применено |
| `SubstanceMap` | `SubstanceId` → индекс `Chem` | динамику клетки |
| `TissueChemistry` | накопление, распад, обмен | нейронную семантику |
| `Blood` | системные реакции и рецепторы | внутреннее состояние клетки |
| `Body` | порядок фаз и смысл сигналов | детали формулы каждого слоя |

## BioCellRuntime

Runtime представляет однородную популяцию клеток. Память хранится column-major: состояние `k` клетки `i` находится в слоте `k * N + i`. Это важно при диагностике и будущей сериализации.

Параметры:

| Параметр | Смысл | Ограничение |
|---|---|---|
| `threshold` | порог активации | не обязан быть положительным, но контракт должен быть явным |
| `releaseGain` | сила связи кальция и выброса | неотрицательный |
| `calciumResponse` | скорость приближения кальция к активации | обычно `[0, 1]` |
| `vesicleRecoveryRate` | восстановление пула за шаг | обычно `[0, 1]` |

Шаг выполняется строго в таком порядке:

```text
activation = max(signal - threshold, 0)
calcium = calcium + (activation - calcium) * calciumResponse
release = min(calcium * releaseGain * vesicles, vesicles)
vesicles = clamp(vesicles - release + (1 - vesicles) * recoveryRate, 0, 1)
```

Состояние `Secretion` — это результат последнего шага, а не бессрочный накопитель. Хост должен забрать его и преобразовать в `BioEvent[]`.

## События и вещества

`SubstanceId` намеренно не равен `Chem`. Например, вид может определить `SubstanceId(2)` как «сигнал благополучия», а конкретное тело связать его с `Chem.Serotonin`:

```csharp
var map = new SubstanceMap(3);
map.Bind(new SubstanceId(2), Chem.Serotonin);
```

Такой маппинг должен создаваться один раз при инициализации, а не вычисляться внутри горячего цикла.

## TissueChemistry

Ткань хранит концентрации по абстрактным веществам и имеет собственный объём. Событие величиной `value` добавляет количество вещества, поэтому:

```text
Δconcentration = value / tissueVolume
```

Перед обменом применяется распад. Затем вещество движется по градиенту, причём количество пересчитывается через объёмы отсеков:

```text
amount = concentration × volume
```

Перенос должен быть ограничен:

- доступным количеством в исходном отсеке;
- свободной ёмкостью крови;
- коэффициентом проницаемости;
- неотрицательной концентрацией.

## Канонический порядок интеграции

```csharp
cells.SetSignal(cellSignals);
cells.Step();

// Пример: один BioEvent на клетку с ненулевой секрецией.
tissue.AbsorbEvents(events);
tissue.StepExchange(blood, bloodVolume, dt, substanceMap);
blood.Update();
```

Фазы нельзя переставлять. Если вызвать `Blood.Update()` раньше обмена, рецепторы увидят вещество на тик позже. Если транспортировать до `Decay`, локальный распад будет нарушен. Если напрямую менять кровь из клетки, исчезнет граница ответственности.

## Тестовый чек-лист

Для клеточного слоя нужны следующие проверки:

1. сигнал ниже порога не выделяет вещество;
2. сигнал выше порога создаёт положительную секрецию;
3. выброс не превышает доступные везикулы;
4. после истощения пул восстанавливается;
5. необязательное вещество без binding не меняет кровь;
6. при нулевой проницаемости обмен отсутствует;
7. перенос сохраняет количество с учётом объёмов;
8. одинаковое состояние даёт одинаковый следующий шаг;
9. снимок и восстановление дают идентичный продолженный прогон;
10. старый сценарий `Blood` без клеток ведёт себя как раньше.

## Ошибки интеграции

**Гормон появляется мгновенно во всей крови.** Обычно это означает, что клеточный и тканевой слои обойдены.

**Клетка напрямую вызывает `Blood`.** Это связывает независимые модули и делает тесты паритета хрупкими.

**Вещество не доходит до крови.** Проверьте `SubstanceMap`, индекс `Chem`, объёмы и направление градиента.

**Обмен создаёт массу из ничего.** Проверьте ограничение `available`, пересчёт через оба объёма и знак градиента.

**Результат зависит от порядка запуска.** Проверьте, что массивы событий очищаются или создаются заново на каждом тике, а random state не глобальный.

## Будущее расширение

Следующий естественный уровень — разные типы клеток, рецепторные профили и тканевые компартменты. Их следует добавлять поверх текущего контракта, не смешивая клеточную секрецию с формулами `Blood` и не меняя default-поведение существующих организмов.
